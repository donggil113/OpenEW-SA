# Frozen report rendering contract

The deliverable is a static scientific PDF/PNG package, not a dashboard. All addendum figures must say POST-HOC. Primary units are 32 equal-weight receivers after five-seed averaging. Packet-weighted reliability bin curves are explicitly descriptive; receiver-equal scalar metrics remain primary.

Figures: receiver macro-F1 (zero-based 0–1 axis); receiver deltas (signed zero line, all receivers); support budget (all prescribed budgets, common-256-reserve query universe); probability metrics (same binning, raw/source-temperature separate); reliability (confidence vs correctness with identity line and sample mass); compute (separate adaptation/inference/support costs); all-receiver reliability small multiples (no receiver selection).

PDF/PNG exports use embedded TrueType fonts, 100% zoom QA, non-color marker/line distinctions. No ranking-dependent axis truncation, selective receivers, favorable support budget highlighting, or oracle/deployable mixing. Intervals only where defined; no invented error bars. Figure source tables and hashes accompany release.

No new scientific inference is introduced by rendering.
