# Proposed Paper 3 release inventory — human review required

No artifact is published by creating this inventory. Each status recommends a future explicit release decision. Sizes are scope estimates from the current checkout, not immutable archive sizes; the release operator must record exact bytes and SHA-256 for the approved file-level package. Approximate checkout sizes checked on 2026-09-30: Paper 3 source tree 2.7 MiB; scripts 1.6 MiB; configs 132 KiB; manuscript tree 1.4 MiB; payload-absent release tree 52 KiB. These trees span multiple Paper 3 workstreams, so the final selected archive may be smaller.
