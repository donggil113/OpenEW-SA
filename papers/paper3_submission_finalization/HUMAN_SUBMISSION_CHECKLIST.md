# Paper 3 human submission checklist

This is a blocking approval checklist, not authorization to submit. All scientific results, methods, splits, seeds, support budgets, figures, tables, and conclusions remain frozen. A technically clean PDF is not a human-approved manuscript.

## Identity and declarations — HUMAN ONLY

- [ ] Authors and author order confirmed by every contributor.
- [ ] Affiliations confirmed.
- [ ] ORCIDs verified; no invented identifiers.
- [ ] Corresponding author designated.
- [ ] Corresponding email verified.
- [ ] Funding statement or explicit no-funding statement approved.
- [ ] Conflict-of-interest statement approved.
- [ ] Exact AI-use disclosure approved: verify OpenAI Codex, Claude, any separate ChatGPT use, exact systems/versions if required, sections affected, degree of assistance, and venue-specific citation/disclosure rules.
- [ ] Target venue and article type chosen (TMLCN or IEEE Access).

## Release and editorial authority — HUMAN ONLY

- [ ] Repository/artifact release policy approved by rights holder and institution, including WiSig derivative and ShareAlike questions.
- [ ] Real code release URL supplied and verified; do not use a guessed URL or DOI.
- [ ] DOI inserted only if one has actually been created.
- [ ] Data Availability wording approved against actual lawful source and release status.
- [ ] Code Availability wording approved against the exact public release.
- [ ] Paper 1/Paper 2 overlap, exclusivity, and related-manuscript disclosure reviewed.
- [ ] Final bibliographic/reference check performed against publisher records, including retraction/correction status.
- [ ] Final PDF visual review completed by authors in the selected venue package.
- [ ] Supplementary upload decision and rights review completed.
- [ ] Selected-venue cover letter approved.

## Technical handoff before human submission

- [ ] Scientific freeze manifest and numerical freeze test pass at the release commit; unexpected scientific changes = 0.
- [ ] Internal and submission builds use the same frozen scientific content, with only metadata/venue presentation changes.
- [ ] Submission PDF has no internal-review banner, private paths, PR/workflow language, unresolved placeholder tokens, or unapproved author claims.
- [ ] Composition oracle and bounded SAR caveats remain visible; post-hoc status is not hidden.
- [ ] TMLCN submission, Access submission, and supplement build with zero errors, undefined citations/references, and Type 3 fonts; check overfull boxes and embedded fonts.
- [ ] File-level release inventory, licence/attribution review, secret scan, and approved download/code destinations match the actual package.
- [ ] Cover letter does not claim external validation, acquired receiver sessions, universal superiority, or a new SAR result.

Until identity, disclosure, availability, release, and venue fields above are approved, status is READY FOR HUMAN METADATA AT MOST, not ready for human submission.
