# Shen external benchmark workstream

This directory records qualification and, only if every gate passes, a blinded
independent multi-receiver LoRa benchmark. It does not modify PR #85 or PR #86.

The workstream distinguishes an acquired-calibration replication from a
bounded, label-free receiver-support benchmark. Neither permits temporal,
dynamic, graph, hypergraph, or neuro-symbolic claims. Generated data and
analysis remain outside Git under `/mnt/d/openew_sa_data/paper3/shen/`.
